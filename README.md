# The Odin Project: Landing Page Project
---
This project aims to showcase what I have learned about CSS and Flexbox through the introductory course on [The Odin Project's website](https://www.theodinproject.com/about).

In this section of the course I learned more about CSS and commonly used properties to help style HTML pages. The biggest lesson I learned was the box model and understanding how elements and items fit and flow with each other. 

The Flexbox section was extremely important in teaching me how to lay out a page and make sure things appear where they should be. One of the extra resources was the perfect website that creates a game to help teach more about flexbox. [Flexbox Froggy](https://flexboxfroggy.com/) is a website where users have to try to use flexbox properties to correctly align different colored frogs to their corresponding lilypads.
